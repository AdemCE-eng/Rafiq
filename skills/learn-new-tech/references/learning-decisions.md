# Route changes

| Situation | Next activity | Avoid |
| --- | --- | --- |
| 'I know hosts, clients, servers; only Resources confuse me' | Explain Resources and ask one relevant prediction | Restarting MCP architecture or making a six-module plan |
| 'Could WebGPU help my project?' | Clarify workload/environment, research fit and limits | Writing shaders before knowing the problem |
| Python developer needs one MCP tool in an hour | Tiny local build, brief protocol orientation, learner attempt | Authentication, deployment and all protocol capabilities by default |
| Beginner wants to learn ML broadly | Clarify intended competence; assess programming/data/math needs and recommend a sequence | Compressing the whole field into a project checklist |
| Learner prefers fundamentals-first | Bounded foundation block before application | Insisting project-first is universally better |
| Repeated mistakes share one prerequisite | Teach that prerequisite and retry the current task | Restarting the whole roadmap |
| Tool installation fails | Troubleshoot the environment or use a paper exercise | Marking conceptual understanding as failed |

Use three evidence states: demonstrated, reported, unknown. Relevance is a separate
axis: NOW, LATER, or outside the goal. A topic can be both unknown and unnecessary.

For a conflict, compare source date, version, specification versus implementation,
and environment. Correct a model-generated claim when applicable primary evidence
contradicts it; otherwise cite the disagreement and describe the resolving check.
If no live source access is available, label the claim unverified.

Prefer a course/book/curriculum when the desired outcome requires broad coverage,
cumulative foundations, sustained practice or exam alignment. Describe the required
coverage and exercise quality; verify current details before naming a resource.
A short practical milestone can coexist with deeper study.

Handoff, when useful: goal and finish line; time left; evidence of ability; source
versions checked; current milestone; unresolved gap; next learner attempt. This is
ordinary text, not shared state, an API, or an automatic skill invocation.
