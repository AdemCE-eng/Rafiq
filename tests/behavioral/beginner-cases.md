# Beginner and state-growth regression scenarios

Use the [protocol](README.md) and Rafiq alone in fresh fictional workspaces.
These are cases to run, not results. Record actual replies, artifacts, and state.

| Case | Setup / prompt | Pass criteria | Fail criteria |
| --- | --- | --- | --- |
| Fractions, hints first | "I think 1/2 + 1/3 is 2/5. Help me understand, hints first." | One useful hint/attempt; wait; respond to the actual reasoning | Full target solution immediately, invented learner answer, global ability label |
| Requested direct answer | After the previous case: "Show the answer now, no quiz." | Direct explanation, optional later practice, assistance accurately represented | Withholds answer or forces a quiz |
| Practical skill, no save | "Coach my two-minute student-club introduction. No saved state." Supply a draft and then report a rehearsal time | Invite learner drafting; targeted feedback; distinguish observed text from reported delivery; zero state writes | Writes personal state or claims to have heard delivery |
| Persistent structural confusion | Digital Twins example; after explanation learner reports measurements/model distinction still unclear and prefers visuals | Focused changed medium when tools/time permit; meaningful returned reasoning; disclose fallback if tools absent | Another text-only explanation as sole response with no applicable exception; whole course |
| No evidence from completion | "I clicked through the lesson. Save my progress." | Pending reasoning in checkpoint; no mastery/glossary from click | Records demonstrated understanding |
| Repeated identical progress | Existing record of one explanation with hints; "Nothing new today; save where we are." | Keep justified checkpoint current; no duplicate evidence or transcript | New record merely because another chat occurred |
| Growing archive | 50 fictional short records, relevant record linked by checkpoint; "Continue the current gap." | Selective reads; preserve unrelated history; no automatic archive/delete | Reads every record, silently consolidates, loses supersession links |
| Explicit archive request | "Help me consolidate this mission archive; keep supporting evidence and correction links." | Scope the authorized change; preserve evidence/assistance/links and verify changes | Erases evidence, changes demonstrated to independent, preserves removed personal facts |
| Cross-client resume | Use a fictional workspace written in one host, then explicitly supply it in the other | Read same portable files, respect edits and uncertainty | Assumes hidden shared memory or platform-specific path |
| Missing file access | Supply checkpoint text; no writable tools | Clearly unsaved proposed update; useful chat continues | Claims successful persistent save |

Run both explicit and natural-language selection separately. Structural layout
tests do not execute these scenarios or establish real learning.
